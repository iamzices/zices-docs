Two computers can sit on the same desk and still send a file on a round trip through the cloud. That is ordinary enough now that the extra trip barely registers.

<!-- truncate -->

Upload it to Drive, then download it on the other machine. Drop it into Discord, then download it again somewhere else. None of this is hard. It is just a strange amount of infrastructure for a file that needs to move from one computer to another.

**[Moment](https://chat.zices.com) is a private, temporary peer-to-peer chat room with file sharing built in. There is no login, and Moment never sees what you send. Messages and files travel peer-to-peer over WebRTC.**

A Moment room can exist for that single transfer. One computer opens the room; the other opens the short link. The file then moves peer-to-peer between the devices, with no account sign-in or cloud folder created just to hold it for a few minutes.

The room also handles smaller things. A URL too long to type or a block of text sitting on the wrong machine can move through the same temporary connection. There is no need to turn either one into an email draft or a saved document first.

That short link becomes especially useful on unfamiliar computers. A transfer can happen without signing a personal account into someone else's machine. It also works when two people are already talking somewhere else and only the file needs a different route.

Discord is a good example. The conversation can stay exactly where it is. When an upload limit gets in the way, or when a file simply does not need to live in Discord's history, a Moment link can handle the transfer instead.

Try Moment at [chat.zices.com](https://chat.zices.com).
