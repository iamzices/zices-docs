# Projects

- [DocFGP](/docfgp/overview)

  DocFGP is a Python library that creates text and visual fingerprints for finding duplicates, near-duplicates, and shared passages across document formats. It supports exact, near-duplicate, and partial-match retrieval, with OCR and visual fingerprints for scanned documents.

- [neo4j-guard](/neo4j-guard/overview)

  neo4j-guard is a Python library that blocks unsafe Cypher queries before execution. It parses Cypher using ANTLR and Neo4j's Cypher 25 grammar, then traverses the resulting syntax tree to validate query operations against built-in safety rules.

- [Chartable](/chartable/overview)

  Chartable is a JavaScript library that makes interactive data visualization easy to use, built on Plotly.js and Tabulator. It draws charts and tables, with buttons to copy and download the data.
