# Projects

- [neo4j-guard](/neo4j-guard/overview): a Python library that blocks unsafe Cypher queries before execution. It parses Cypher using ANTLR and Neo4j’s Cypher 25 grammar, then traverses the resulting syntax tree to validate query operations against built-in safety rules.
